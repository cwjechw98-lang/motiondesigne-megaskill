# Установка без переделки харнесса

## Что требуется

Для использования инструкций — агент, умеющий читать локальные файлы навыков или обычный SKILL.md. Для галереи — современный браузер. Для необязательного установщика, тестов и валидатора — Node.js 20+. Обязательных npm-зависимостей, сервера и API-ключей нет. Для создания конкретного видео могут потребоваться инструменты, которых в этом пакете нет.

## Ручная установка

1. Скачайте репозиторий обычным способом либо клонируйте его по HTTPS.
2. Узнайте из документации **вашего** агента, где находятся пользовательские навыки. Не используйте установочный каталог приложения и не угадывайте путь по чужому харнессу.
3. Поместите комплект в отдельную папку `motion-design-megaskill` с SKILL.md в корне. Сохраняйте структуру references, assets и файлов галереи. `.git` и локальные тестовые артефакты копировать не нужно.
4. Обновите каталог навыков/создайте новую сессию так, как требует ваша среда. Убедитесь, что агент видит название и читает SKILL.md.
5. Вызовите навык с простым брифом. Он должен предложить осмысленные варианты и помочь продолжить, а не немедленно править shell.

Если автообнаружения нет, попросите агента прочитать SKILL.md как дополнительную инструкцию. Это не равнозначно официальной нативной поддержке, но не требует изменения глобальной роли.

## Локальный установщик

Запускается из скачанного репозитория и не обращается к сети. **Цель — полный путь отдельной папки этого навыка**, а не общий каталог всех навыков. Установщик не знает и не выбирает путь за вас.

```sh
node scripts/install.mjs --help
node scripts/install.mjs --target "<полный-каталог-навыка>" --dry-run
node scripts/install.mjs --target "<полный-каталог-навыка>"
```

Вместо угловых скобок нужен реальный абсолютный путь в вашей среде. Сначала dry-run: он не должен создавать файлов. Никаких shell-патчей, автозапуска и регистрации провайдеров.

Если цель существует, обычная установка откажется. Для явного обновления:

```sh
node scripts/install.mjs --target "<полный-каталог-навыка>" --replace --dry-run
node scripts/install.mjs --target "<полный-каталог-навыка>" --replace
```

Замена сначала подготавливает копию, затем сохраняет целевую папку рядом как резервную и переключает новую версию. Путь резервной копии выводится после успеха. Тесты проверяют сохранность прежней версии при ошибках копирования и финального переименования. Это не защита от активной конкурентной подмены файлов злонамеренным процессом; не запускайте одновременно несколько установок в одну цель. Символические ссылки/пересекающиеся деревья отвергаются.

## Проверка

Из корня комплекта:

```sh
node scripts/validate.mjs
```

Из исходного репозитория, где есть тесты:

```sh
node --test
```

Откройте gallery.html в обычном браузере, проверьте превью, поиск, карточку и копирование. Потом проверьте фактическую загрузку навыка вашим агентом. Эти проверки различны: валидный пакет ещё не доказывает обнаружение навыка конкретным продуктом.

## Необязательная интеграция

Попросите агента изучить [playbook](../references/integration-playbook.md). Он должен проверить реальные API и выбрать минимальный вариант — от обычной галереи до штатного расширения. Универсального готового плагина в пакете нет. Не снимайте CSP, не включайте произвольные привилегии iframe и не патчите файлы приложения только ради панели.

## Обновление и пользовательские данные

Свои рецепты, избранное и настройки адаптера храните вне папки заменяемого релиза. При обновлении сохраните резервную копию, проверьте изменения и повторите тесты среды. API расширения может измениться; локальная галерея — fallback. Автоматического обновления и фоновых процессов нет.

## Удаление

Отключите необязательный адаптер штатным способом, затем переместите или удалите только папку этого навыка. Не удаляйте общий каталог навыков. Отдельно сохранённые пользовательские рецепты и резервные копии удаляются только по вашему решению.
